# Use APISIX AI Gateway with reversible tokenization

The `apisix-plugin-example` is a functional AI proxy gateway, not a mock-only demonstration or a hand-written replacement for APISIX AI Gateway. We will use APISIX AI Gateway components for the OpenAI-compatible request/response pipeline and safety enforcement, while preserving the product privacy contract that PII handling must produce reversible tokens rather than irreversible masking/redaction. If APISIX built-ins only provide masking, they are insufficient on their own and must be paired with the smallest integration needed to apply the project's reversible tokenization semantics. The core library may be extended with direction-aware semantic-content helpers, but it remains a library for injection checking and secret guarding primitives, not routing infrastructure, an HTTP server, or a network proxy.
